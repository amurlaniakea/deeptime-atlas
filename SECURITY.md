# Security policy

Deep Time Atlas is a static web page with no backend and no user accounts. It makes no network
requests at run time and ships with a strict Content-Security-Policy.

To report a vulnerability, use GitHub's **private vulnerability reporting** (Security tab of this
repository) or write to amurlaniakea@gmail.com. Please do not open a public issue for security problems.

Scientific errors in the data are not security issues: report them as normal issues
(see `CONTRIBUTING.md`).
